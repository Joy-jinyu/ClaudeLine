Please use the commit-message skill to provide guidance on commit message best practices and help with commit message creation.

This command gives you access to the full commit-message skill capabilities:

## Available Functions

1. **Generate commit messages** from git changes
2. **Validate existing commit messages**
3. **Provide commit type guidance**
4. **Suggest scopes** based on file changes
5. **Format multi-line commits** with body and footer

## Common Use Cases

- "Help me write a commit message for my changes"
- "What commit type should I use for adding tests?"
- "Check if this message follows best practices: [message]"
- "I need a commit message for a breaking change"
- "How should I structure a commit with multiple changes?"

## Supported Commit Types

- **feat**: New features
- **fix**: Bug fixes
- **docs**: Documentation changes
- **style**: Code formatting (no logic change)
- **refactor**: Code restructuring
- **perf**: Performance improvements
- **test**: Adding/updating tests
- **chore**: Maintenance tasks
- **build**: Build system changes
- **ci**: CI configuration changes

The skill follows Conventional Commits specification and will help you create professional, standardized commit messages.
